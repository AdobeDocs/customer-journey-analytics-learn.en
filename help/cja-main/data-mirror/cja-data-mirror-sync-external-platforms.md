# Data Mirror for [!DNL Customer Journey Analytics]

Keeping customer data consistent across cloud data warehouses and [!DNL Customer Journey Analytics] (CJA) can be challenging. Organizations often rely on manual processes to synchronize updates, which adds work for data engineering teams and increases the risk of discrepancies between systems.

Data Mirror simplifies this process by automatically reflecting changes from supported cloud data warehouses, such as Snowflake, BigQuery, and Databricks, into CJA. By reducing manual effort and keeping systems aligned, teams can trust that the data used for analysis stays up to date. This video demonstrates how Data Mirror works and walks through the steps to configure it in Adobe Experience Platform.

For additional information, please visit the [documentation](https://experienceleague.adobe.com/en/docs/analytics-platform/using/cja-data-mirror/relational){target="_blank"}.
