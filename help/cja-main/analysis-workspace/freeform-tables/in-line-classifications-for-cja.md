# Use in-line classifications for Customer Journey Analytics

In-line Classifications for CJA lets you make on-the-fly edits directly within Analysis Workspace by updating a value in a table or grouping multiple values together. It brings a small but powerful slice of Derived Fields functionality directly into the Workspace experience.
